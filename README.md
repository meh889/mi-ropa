# Edna

¿Dónde está mi súper traje?

Vestidor personal para el iPhone: registro de prendas con foto, talle, marca y color, armarios, outfits guardados y un generador de outfits por ocasión y temperatura.

Abrila en Safari desde https://meh889.github.io/mi-ropa/ y tocá Compartir → "Agregar a inicio". Los datos y las fotos se guardan solo en el teléfono; usá "Guardar copia" (en Armarios) para tener un respaldo en iCloud Drive.
